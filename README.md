# 数学自学知识库

中文数学主干与高阶入门学习资源 · v1.1。由项目维护者组织、AI辅助编写与审查；不是经外部专家审定的正式教材。

## 直接使用

下载仓库后，在现代浏览器打开 [开始阅读.html](开始阅读.html)。阅读、搜索、图解、学习状态与笔记均可离线使用；点击第三方来源才需要联网。GitHub文件预览不是已部署的在线网站。

- 初中45、高中40、高阶18，共103个模块，324个概念条目。
- 103道讲解例题、287道常规自测；12张深化卡另有24道入门与迁移检测。
- 12张卡补充逐步自学讲解、错解诊断和针对性回读；其余91张仍为基础卡，未冒称全库都已详细重写。
- 8幅自行绘制的数学SVG图解；18个高阶模块说明假设、证明依赖及推导。

推荐先查看首页12个自学示范入口。做题先写过程再展开答案；一次做对不等于整个专题掌握。

## 数学与教学质量

[审查报告](06_严谨性与自学审查.md) 列出定义修正、隐性先修、详细讲解标准与未完成事项。[验证说明](05_验证说明.md) 区分结构检查、数值抽查和浏览器测试。数学一般命题不能由有限数值测试替代证明。

没有虚构地区考试权重；高阶工具不自动属于当地考试允许直接引用的方法。第三方资料不随仓库分发，详见[公开来源](02_来源与版本核查.md)。

## 维护与构建

安装Node.js 18或以上版本即可；不需要安装npm依赖。

```text
node 构建工具/build_diagrams.mjs
node 构建工具/build_kb.mjs
node 构建工具/verify_v11.mjs .
```

先改data中的基础JSON，或扩充资料中的分层题／详细讲解，再构建。不要只改会被覆盖的生成稿。编号保持稳定，来源不得伪造，练习不要冒称真题。协作要求见[CONTRIBUTING.md](CONTRIBUTING.md)。

## 隐私

页面没有后端，也不发送学习记录。状态与笔记只保存在当前浏览器，请手动导出备份；不要把含个人笔记的进度JSON提交到公开仓库。原教材PDF、私人链接、账号信息和聊天记录已排除。
